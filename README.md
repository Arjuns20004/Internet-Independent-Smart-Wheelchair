# 📌 Overview

The **Internet-Independent Smart Wheelchair** is an intelligent embedded mobility system developed for physically challenged individuals and elderly users. The system integrates multiple control methods and advanced safety mechanisms into a unified assistive platform.

Unlike traditional smart wheelchairs, this system operates completely **without internet dependency**, ensuring reliable real-time performance in rural, medical, and low-network environments.

---

# ✨ Major Features

## 👁️ Eye Blink Control

* Real-time eye blink detection
* Multi-blink movement control
* Assistive navigation for paralysis patients

## 🎙️ Offline Voice Control

* VC-02 AI Offline Voice Module
* Internet-free voice processing
* Hands-free wheelchair operation

## 🎮 Joystick & Touchpad Control

* Manual navigation support
* Smooth directional control
* User-friendly operation

## 🚧 Obstacle Detection

* HC-SR04 ultrasonic sensor
* Real-time collision prevention
* Automatic wheelchair stopping mechanism

## 🚨 Fall Detection & GSM Alert

* ADXL345 accelerometer monitoring
* Emergency fall detection
* GSM-based SMS alert communication

## 🔐 RFID Authentication

* Authorized user access
* Enhanced wheelchair security
* RFID-based unlocking system

## ☔ Automatic Shelter System

* Rain detection mechanism
* Servo-controlled shelter automation
* User environmental protection
